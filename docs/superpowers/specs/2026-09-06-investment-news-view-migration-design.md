# 资讯看板迁移与股票助手入口设计

## 目标

将 `C:\Users\11982\Desktop\搭建\investment-news-assistant` 的资讯页面文件内容直接复制并替换当前项目的“资讯看板”视图。资讯页面继续使用该项目现有的 HTML/CSS/JavaScript、新闻源、记忆、收藏、行情和研究接口；当前项目原有资讯看板组件及其后端接口不再作为资讯看板使用。

保留当前项目的股票助手及其前后端实现，股票助手端所有文件和逻辑完全不动，不删除、不重写、不迁移。仅对复制后的资讯端做入口衔接：资讯项目中原“行情工作台”所在位置改为“股票助手”，顶部蓝色 AI 按钮保留视觉入口但删除其原有抽屉内容和交互；点击入口后，在当前浏览器标签页进入当前项目的股票助手。

## 范围与非目标

本次只处理资讯看板替换与股票助手入口衔接：

- 包含：直接复制资讯项目页面文件、资讯项目资源和 API 接入、移除原行情工作台入口、改造蓝色 AI 按钮为股票助手入口、当前标签页导航、主入口状态恢复。
- 不包含：任何股票助手端文件和逻辑的修改，包括 UI、会话、模型配置、记忆层、研究工作台、后端路由和数据结构。
- 不包含：对资讯项目新闻源、资讯卡片、收藏、记忆、行情和研究逻辑做产品级改造。

## 架构方案

采用“资讯文件直接复制 + 当前项目保留原股票助手”的边界方案：

1. 当前项目的根入口继续由 Vite/React 提供。
2. 将资讯项目可运行所需的页面文件、脚本、样式和静态资源直接复制到当前项目的资讯端目录；不将资讯页面重写为 React 组件。
3. 资讯项目的 API 请求继续指向其自己的服务（默认 `127.0.0.1:8888`），不映射为当前项目的 `/news/*` API。
4. 当前项目的股票助手继续由现有 `App.tsx` 中的 `AgentWorkspace` 渲染，并继续请求当前项目后端（默认 `127.0.0.1:8000`）；实现迁移时不得改动该组件及其依赖。
5. 通过 URL 查询参数或等价的可恢复入口区分资讯视图和股票助手视图，保证刷新后仍停留在当前页面。

## 页面与交互

### 资讯看板

- 使用图片项目的资讯页面布局和行为。
- 删除左侧“行情工作台”按钮。
- 在该位置显示“股票助手”按钮。
- 顶部蓝色 AI 按钮保留按钮外观和位置，但移除原 AI 抽屉、消息、提问、记忆操作及其相关脚本绑定。
- 点击顶部蓝色 AI 按钮或左侧“股票助手”按钮，都在当前标签页进入股票助手；不打开新标签页，不保留原 AI 抽屉。

### 股票助手

- 使用当前项目现有 `AgentWorkspace`，包括会话、流式对话、模型设置、记忆、研究画布、数据管理等现有功能。
- 从股票助手返回资讯页时，回到迁移后的资讯页面。

## 数据流与服务边界

```text
浏览器 127.0.0.1:5174
  ├─ 资讯视图 ──> investment-news-assistant 页面资源
  │              └─ 资讯 API/数据源 ──> 127.0.0.1:8888
  └─ 股票助手视图 ──> 当前 React AgentWorkspace
                 └─ 股票助手 API ──> 127.0.0.1:8000
```

实现时优先直接复制并运行资讯项目文件，避免把资讯业务逻辑改写成 React；如开发服务器的资源或跨域限制阻止原样运行，只增加最小必要的静态资源代理/配置，不改变资讯业务接口，也不触碰股票助手端。

## 错误处理

- 资讯服务不可用时，资讯视图显示明确的连接失败提示和服务地址，不影响股票助手入口。
- 股票助手服务不可用时，继续使用当前项目现有错误提示，不新增第二套错误处理逻辑。
- 页面跳转使用明确的 URL 状态，避免返回或刷新后进入错误视图。

## 验收标准

1. 打开 `http://127.0.0.1:5174/`，看到的是图片项目的资讯页面，而不是当前旧资讯看板。
2. 图片项目的新闻、新闻源、收藏、记忆、行情和研究操作仍能调用原有数据服务。
3. 左侧原“行情工作台”入口消失，原位置出现“股票助手”。
4. 顶部蓝色 AI 按钮仍可见，但不再打开原 AI 抽屉或触发原 AI 对话。
5. 点击任一股票助手入口后，当前标签页进入股票助手；地址刷新后仍保持股票助手视图。
6. 股票助手端相关文件和逻辑与迁移前完全一致；其会话、流式回复、模型配置、记忆和研究功能继续可用。
7. 股票助手返回资讯页后，仍显示迁移后的资讯页面。
8. 运行前端构建/类型检查，并完成一次资讯入口和股票助手入口的浏览器验证。

## 回滚边界

所有迁移改动必须通过 Git 提交记录保存。若验收失败，可以只回滚本次迁移提交，恢复当前项目原资讯看板和原入口；股票助手相关文件不得在本次迁移中被删除、复制覆盖、重写或格式化。
